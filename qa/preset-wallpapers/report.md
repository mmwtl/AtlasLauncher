# Встроенные фоны — 2026-09-27

## Изменение

В настройках рабочего стола добавлена горизонтальная лента из 12 фонов из `~/Downloads/fon/`. Нажатие сразу применяет изображение и обновляет предпросмотр. Выбор хранится в существующем ключе `home.wallpaper` как `android.resource://com.mmwtl.atlaslauncher/drawable/<name>`: числовые ID ресурсов не сохраняются. Выбор своего файла и возврат стандартного фона сохранены.

Изображения: WebP quality=92, method=6, исходные 1086×1448 без апскейла, суммарно 1 605 010 байт. Ресурсы размещены в `drawable-nodpi`; миниатюры декодируются с `inSampleSize`, без загрузки всех полноразмерных изображений в память. Сравнены фрагменты машины, световых линий и города при исходном масштабе: заметного ухудшения чёткости не обнаружено; сжатие с потерями.

Первоначальные 11 PNG дополнены появившимся во время работы `e28ee00b-dd37-47b0-aac7-00ee711c1e48.png` («Горный закат»). `Изображение ChatGPT 27 сент. 2026 г., 11_02_07.png` побайтово совпадает с первоначальной машиной `10_51_59.png`, поэтому второй экземпляр не включён. Исходники не изменены.

## Проверка

Устройство: `emulator-5554`, Android 11, sdk_gphone_arm64, 1440×1920, density 160. APK: debug `0.4.0` (4), установлен обновлением без очистки данных. HOME по умолчанию не изменялся.

- `:app:assembleDebug` — успешно.
- `:app:testDebugUnitTest` — `NO-SOURCE`, JVM-тестов нет.
- `:app:lintDebug` — блокируется существующей ошибкой `ExpiredTargetSdkVersion`, targetSdk=30. SDK и правила Lint не менялись.
- Все 12 миниатюр выбраны нажатием, включая варианты после горизонтальной прокрутки; после каждого выбора проверен соответствующий URI в SharedPreferences.
- «Внедорожник» сохраняется после force-stop и повторного запуска Activity; фон виден на рабочем столе и в настройках.
- «Выбрать изображение» открывает системный выбор; отмена возвращает в настройки. Новый пользовательский файл не импортировался.
- «Вернуть стандартный фон» удаляет выбор; после этого содержимое SharedPreferences совпало с исходным, включая размещение виджетов, часы и док.
- В crash buffer нет падения AtlasLauncher. Во время настройки автоматизации зарегистрировано падение самого `uiautomator` из-за пересечения двух UI-дампов. Последующая автоматизация выполнялась последовательно.
- Стандартный `uiautomator dump` не дожидался покоя из-за обновлений активных виджетов. Использован временный UIAutomator helper с `waitForIdleTimeout=0`; координаты нажатий брались из дерева UI. Helper не входит в APK.
- `git diff --check` — успешно.

На физическом ГУ не проверено. Добавление/перемещение/повторная настройка сторонних виджетов не затрагивались и заново не тестировались.
