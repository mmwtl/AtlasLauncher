# Миниатюры в окне добавления виджетов — 2026-09-28

## Изменение

Текстовый список `＋` заменён окном в стиле каталога приложений. Это сетка карточек с миниатюрой, названием, приложением и минимальным размером в ячейках. Миниатюра берётся из `AppWidgetProviderInfo.loadPreviewImage`, при её отсутствии — из `loadIcon`. Изображения загружаются в одном фоновом потоке и уменьшаются так, чтобы длинная сторона была не больше 300 dp. После закрытия окна загрузка прекращается. Для встроенных часов показывается живой `TextClock`, для дока — два его приложения и кнопка «Все приложения». `previewLayout` (API 31+) не используется: ГУ работает на Android 11. Логика привязки, настройки и размещения не изменена.

## Проверка

Устройство: `emulator-5554`, Android 11 (API 30), 1440×1920, density 160. APK: debug `0.5.0` (15), установлен обновлением без очистки данных.

- `:app:assembleDebug` — успешно.
- `:app:lintDebug` — блокируется существующей ошибкой `ExpiredTargetSdkVersion`; в новом коде замечаний нет.
- В окне показано 23 виджета: у всех сторонних есть превью, у встроенных часов и дока — собственный предпросмотр.
- «Analog clock» добавлен из нового окна, размещён без перекрытий и затем удалён.
- После force-stop и повторного запуска расположение прежних виджетов, часов и дока не изменилось. В crash buffer нет записей AtlasLauncher.
- `git diff --check` — успешно.

Не проверены: запрос разрешения на привязку (на эмуляторе привязка прошла без него), виджет с экраном настройки, поведение на физическом ГУ. Качество миниатюр OEM-виджетов на ГУ зависит от их `previewImage`.
