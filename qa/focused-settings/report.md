# Отдельные окна настроек

Дата: 2026-09-27. Устройство: `emulator-5554`, `sdk_gphone_arm64`, Android 11 / API 30, 1440×1920, 160 dpi. Версия приложения: 0.4.0 (4), debug.

## Итоговое поведение

- Общая шестерёнка открывает модальное графитовое окно с разделами «Рабочий стол» и «Система», предпросмотром фона и переходами к редактированию, каталогу и Android.
- Параметры дока остаются на доке, параметры часов — на часах. Их окна используют то же оформление. В общих настройках этих разделов нет.
- Изменения сохраняются сразу. Заголовок и кнопка «Готово» остаются видны при прокрутке. Закрытие: «Готово», ×, Back. Нажатие снаружи блокируется.
- У часов есть живой предпросмотр; изменение параметров обновляет существующий вид часов без пересоздания сторонних AppWidget.

## Проверки

| Сценарий | Результат |
| --- | --- |
| Общая шестерёнка, переключение «Рабочий стол» / «Система» | Оба раздела открываются внутри одного окна; дока и часов в навигации нет |
| Нажатие на шестерёнку рабочего стола за модальным окном | Окно остаётся открытым, касание не проходит к рабочему столу |
| Выбор изображения, отмена системного выбора | Возврат в настройки рабочего стола без потери окна |
| Переход в настройки Android и Back | Возврат к разделу «Система» |
| Док: долгое нажатие на значок | Открывается отдельное окно дока без общей навигации |
| Компактность, подписи, видимость кнопки каталога | Переключатели применяются; значения проверены в preferences после force-stop/relaunch |
| Порядок приложений | Maps перемещён вправо и обратно; список и док обновляются |
| Выбор действия кнопки, добавление приложения, отмена | Вложенные списки открываются и возвращают в окно дока |
| Прокрутка длинного списка дока и параметров часов | Нижние параметры доступны; заголовок и «Готово» неподвижны |
| Часы: 24-часовой формат, дата, начертание, моноширинный шрифт | Предпросмотр и часы обновляются; значения сохраняются после force-stop/relaunch |
| Системный масштаб текста 1.3, затем возврат к исходному | Activity пересоздаётся, окно часов восстанавливается с выбранными параметрами; текст читается |
| Идентификаторы и размещение существующих виджетов | ID сторонних виджетов 17 и 20, их координаты и размеры, а также геометрия часов сохранены; док расширяется при включении подписей согласно существующему поведению |
| Вход в редактирование из общего окна, список виджетов и отмена | Окно настроек закрывается, элементы редактирования доступны; отмена не добавляет виджет |
| Общие настройки → каталог → поиск Files → запуск | Поиск фильтрует список, Files запускается |
| Закрытие через «Готово», ×, Back | Возврат на рабочий стол / к родительскому окну |
| Crash buffer logcat | Падений в проверенном сеансе не обнаружено |

Изменённые при проверке пользовательские параметры часов и переключатели дока возвращены к исходным значениям; системный `font_scale` возвращён к исходному отсутствующему значению. Док уменьшен обратно до одной ячейки; итоговый JSON размещений всех виджетов совпадает с исходным.

## Сборка

Использованы JDK 17, локальный Android SDK, Gradle Wrapper и `ANDROID_USER_HOME="$PWD/.android-user"`.

- `:app:assembleDebug` — успешно.
- `:app:testDebugUnitTest` — `NO-SOURCE`; JVM-тестов нет.
- `:app:lintDebug` — ожидаемая существующая ошибка `ExpiredTargetSdkVersion` (`targetSdk=30`), не подавлялась. Финальный общий рабочий каталог: 1 ошибка, 14 предупреждений; до параллельной правки иконки было 13 предупреждений.
- `git diff --check` — без ошибок.

Во время проверки в рабочем каталоге параллельно менялись иконка, имя APK и конфигурация подписи. Эти изменения не относятся к данной доработке. После появления всех ресурсов повторная сборка прошла, установлен финальный debug APK из `app/build/outputs/apk/debug/0.4.0[4]AtlasLauncher-debug.apk`. SHA-256 APK: `6fb947c2a3404a64b38b2f1312ea3f6728566f8c417c2756b9e1cc30ce41b68c`. Данные приложения не очищались, HOME по умолчанию не переключался.

## Ограничения

Реальное ГУ OneOS, OEM SystemUI и климат не проверялись. Полный цикл привязки и повторной настройки сторонних AppWidget не повторялся: соответствующий код не изменялся. Выбор нового изображения до подтверждения, ручной ввод Activity и все варианты запуска внешних Activity в этой проверке не проходились. Узкие телефонные экраны отдельно не проверялись.
