# Кнопка «Домой» на панели климата без мелькания Launcher3

Дата: 2026-10-05. Устройство: ГУ ATLAS ОД (OneOS, Android 11). APK `1.0.0-dock-home-click-redirect[16]AtlasLauncher-release.apk` (release-подпись), переключатель ««Домой»: возвращать на AtlasLauncher» включён, служба подключена.

## Изменение

`StockHomeRedirectService` при включённой функции «Домой» получает `TYPE_VIEW_CLICKED` панели и по нажатию на первый элемент `rv_nav_main` (кнопка «Домой», `itemId=100`, `dock_main`, позиция 0, `canMove=0` по `dockPresetData.json` плагина) сразу запускает AtlasLauncher. Перехват по окну `com.android.launcher3.Launcher` оставлен запасным путём.

## Проверено на ГУ (пользователем)

- Нажатие «Домой» на панели из другого приложения открывает AtlasLauncher без видимого мелькания Launcher3.

## Не проверено

- Поведение других кнопок панели и «Все приложения» с этой сборкой отдельно не фиксировалось (логика «Все приложения» не менялась).
- Холодный старт процесса AtlasLauncher в момент нажатия; переставляемость кнопок на других прошивках (на ATLAS ОД кнопки панели переставлять нельзя).
