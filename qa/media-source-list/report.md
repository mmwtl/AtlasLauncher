# Список источников штатного медиавиджета

## Проблема

`com.geely.mediawidget` (`SourceWidgetProvider`, `SourceBigWidgetProvider`) по нажатию на `rl_swicth_area` / `iv_mediaWidget_switch` / `iv_marker` вызывает `content://com.android.launcher3.interactive`, метод `media_source_show`. Launcher3 показывает над виджетом `PopupWindow` с AppWidget `SourceListWidgetProvider`. Если окна Launcher3 нет (HOME — Atlas), вызов игнорируется. Authority провайдера занят Launcher3, объявить такой же в Atlas нельзя.

## Решение

Контейнер виджета из пакета `com.geely.mediawidget` отслеживает касания (не перехватывая их). Если касание-тап попало в один из трёх элементов переключателя (ID берутся из ресурсов пакета, для этого пакет добавлен в `<queries>`), Atlas показывает над виджетом `PopupWindow` с `SourceListWidgetProvider`. ID этого виджета хранится в `SharedPreferences("home")` под ключом `source_list_widget` и не удаляется очисткой «лишних» ID при запуске. Окно выровнено по низу, поэтому при подгрузке строк растёт вверх. Закрывается касанием снаружи, через 300 мс после тапа внутри (выбор источника: сам виджет сообщает об этом только Launcher3), в `onStop` и при перестроении сетки.

## Размер и скругление карточки

Launcher3 держит виджеты без отступов хоста (`LauncherAppWidgetHostView.setPadding(0, 0, 0, 0)`), а корень разметки медиавиджетов имеет фиксированный размер в пикселях, больше объявленного минимума: `SourceWidgetProvider` 516×224 при `minWidth/minHeight` 392×184, `SourceBigWidgetProvider` 480×480 при 392×392. Скругление нарисовано в фоне карточки (`card_bg.png`, `big_widge_bg.webp`), Launcher3 углы не обрезает (`mEnforcedCornerRadius` всегда 0). Atlas брал объявленный минимум и стандартные отступы Android, поэтому карточка обрезалась справа/снизу вместе со скруглениями, а список казался шире карточки.

Теперь для пакета `com.geely.mediawidget` Atlas не добавляет отступы, минимальный размер (каталог, добавление, изменение размера) берёт из корня `initialLayout`, а сам хост — ровно размером карточки по центру ячейки. Список источников выравнивается по карточке: низ — по её верху, по горизонтали — по центру.

## Проверка

Эмулятор `atlashu` (Android 11, API 30, 1440×1920, 160 dpi), debug APK `0.5.0[15]`, на эмулятор установлен `reference-apks/oneOS_MediaCenterUI.apk`.

| Шаг | Результат |
| --- | --- |
| Добавить штатный медиавиджет через `＋` | Добавлен, привязка прошла без диалога (разрешение уже было выдано на эмуляторе) |
| Тап по значку источника | Появилось окно `PopupWindow` 480 px шириной, низ — на верхней границе `AppWidgetHostView` ([снимок](emulator-popup.png)) |
| Тап вне окна | Закрылось |
| Тап внутри окна | Закрылось |
| Тап по другой части виджета | Окно не открывается |
| HOME, долгое нажатие (режим редактирования) | Закрывается / не открывается |
| Большой виджет (`SourceBigWidgetProvider`) | Карточка 480×480 целиком, со скруглёнными углами; список той же ширины встаёт ровно над ней ([снимок](emulator-cards.png)) |
| Малый виджет (`SourceWidgetProvider`) | В каталоге 6×3 (было 5×3), карточка 516×224 целиком по центру ячейки 576×288; список 480 px по центру над ней (x = левый край карточки + 18) |
| Подписи в каталоге | У приложения пустое имя; показывается имя пакета, как до добавления `<queries>` |
| force-stop и повторный запуск | ID `SourceListWidgetProvider` сохранился и переиспользуется, второй не создаётся |

`lintDebug`: кроме ожидаемой `ExpiredTargetSdkVersion`, новое предупреждение `DiscouragedApi` на `getIdentifier` — ID элементов чужого пакета иначе не получить.

## Ограничения

- На эмуляторе нет медиасервиса Geely: у виджета нет обработчиков нажатий, а список пуст (видна только белая полоса отступов). Поэтому код временно проверялся с срабатыванием на `ACTION_DOWN`; финальный вариант проверен тапами, так как касания доходят до контейнера через долгое нажатие `AppWidgetHostView`. Реальный вид списка, выбор источника и его закрытие нужно проверить на ГУ.
- Высота окна берётся из содержимого, а не из `height`, который виджет передаёт Launcher3.
- Если над карточкой мало места, список прижимается к верхнему краю экрана и перекрывает карточку, как `showAsDropDown` в Launcher3. Размещайте медиавиджет ниже.
- Уже размещённые медиавиджеты при первом показе увеличиваются до размера карточки, если рядом есть место.
- Диалог разрешения на привязку не проверялся; после разрешения список открывается следующим нажатием.
- Launcher3 по-прежнему получает `media_source_show`; без его окна он запрос отбрасывает (`window token == null`), но если Launcher3 жив в фоне, он может показать окно у себя — невидимо, пока открыт Atlas.
