# Настройки виджетов только на виджетах

Дата: 2026-09-29. Устройство: эмулятор `atlashu`, `sdk_gphone_arm64`, Android 11 / API 30, 1440×1920, 160 dpi. Версия приложения: 0.5.0 (15), debug.

## Итоговое поведение

- Общая шестерёнка открывает одну страницу без вкладок: «Фон рабочего стола», «Рабочий стол» (переход к редактированию) и «Система». Пункт «Все приложения» из общих настроек убран.
- Док и часы настраиваются только шестерёнкой на самом виджете в режиме редактирования, как и сторонние виджеты.
- Долгое нажатие на док, в том числе на его значки и кнопку «Все приложения», включает режим редактирования, как у остальных виджетов.
- Выбранный встроенный фон обведён синей рамкой; «Вернуть стандартный фон» снимает рамку.
- В настройках дока размер значков — ползунок без числа в dp; своё действие кнопки «Все приложения» показано названием приложения/Activity, а не именем компонента.

## Проверки

| Сценарий | Результат |
| --- | --- |
| Общая шестерёнка | Одна страница с тремя карточками, вкладок нет; «Система» доступна прокруткой |
| Выбор встроенного фона, затем «Вернуть стандартный фон» | Фон и предпросмотр меняются, рамка переходит на выбранную миниатюру и снимается при сбросе |
| Долгое нажатие на значок Gmail в доке | Включается режим редактирования, окно настроек не открывается |
| Шестерёнка дока в режиме редактирования | Открывается окно «Док приложений» |
| Действие кнопки: ручной ввод `com.google.android.deskclock/com.android.deskclock.DeskClock` | Кнопка показывает «Открывать: Clock»; возврат к встроенному каталогу — «Открывать: встроенный каталог» |
| Шестерёнка часов в режиме редактирования | Открывается окно «Настройки часов» |
| Масштаб шрифта 1.3 при открытом окне дока, затем возврат к 1.0 | Activity пересоздаётся, окно дока восстанавливается |
| Back в окне дока | Окно закрывается, режим редактирования остаётся |
| `logcat -b crash` после проверки | Новых сбоев нет |
