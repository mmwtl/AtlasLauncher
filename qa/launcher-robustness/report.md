# Устойчивость HOME: док, виджеты, Home

Дата: 2026-09-28. Устройство: `emulator-5554` (AVD `atlashu`), Android 11 / API 30, 1440×1920, 160 dpi. Версия: 0.5.0 (15), debug, установлена поверх 0.4.0 (4) с сохранением данных.

## Изменения

- Закреплённые приложения больше не удаляются из сохранённого списка, если PackageManager их не вернул (отключение, обновление, временная недоступность). В настройках дока такие записи помечены «недоступно».
- Список приложений перечитывается по событиям установки, удаления и изменения пакетов, а не при каждом `onResume`. Возврат на HOME больше не пересоздаёт все AppWidgetHostView; обновляются только часы (системный формат 12/24).
- Home закрывает каталог, окна настроек и режим редактирования.
- Настройка AppWidget запускается через `AppWidgetHost.startAppWidgetConfigureActivityForResult`, поэтому работает и с неэкспортированными Activity настройки.
- При запуске удаляются ID виджетов, привязанные к хосту, но не принадлежащие ни одному размещению (обрыв питания или force-stop во время привязки/настройки).
- «Открыть штатный Launcher3» запускает явный компонент `com.android.launcher3/.Launcher`. В OEM APK четыре Activity с `LAUNCHER`, первой объявлена `CarLinkStatusActivity`, поэтому `getLaunchIntentForPackage` мог открыть не тот экран.

## Проверки

| Сценарий | Результат |
| --- | --- |
| Обновление 0.4.0 → 0.5.0 | Часы, док, виджеты 17 и 20 на прежних местах; prefs после всех проверок совпадают с исходными |
| `pm disable-user` Gmail при открытом HOME | Значок исчез из дока сразу; запись сохранена в prefs и после force-stop/relaunch; в настройках дока показано `com.google.android.gm · недоступно` ([снимок](dock-unavailable-app.png)) |
| `pm enable` Gmail при открытом HOME | Значок вернулся в док без перезапуска |
| Открыты настройки дока / каталог / режим редактирования, затем Home | Каждое закрыто, рабочий стол чистый |
| Добавление виджета Gmail (с Activity настройки) | Настройка запущена через API хоста; ID 22 выделен |
| Force-stop во время настройки, повторный запуск | Осиротевший ID 22 удалён из хоста; 17, 20, часы и док сохранены |
| Отмена настройки (Back) | После возврата на HOME ID 23 удалён, размещение не добавлено |
| Crash buffer | Пуст |

## Ограничения

- Запуск `com.android.launcher3/.Launcher` не проверен: в эмуляторе установлен AOSP Launcher3 с другим классом HOME. Проверить на ГУ по [протоколу](../../docs/head-unit-test-and-rollback.md).
- Смена системного формата 12/24 при выбранном «Как в системе» не проверялась отдельно (на эмуляторе выбран 12-часовой формат).
- Работа на реальном ГУ OneOS не проверялась.
