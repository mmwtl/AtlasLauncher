<h1 align="center">Atlas Launcher</h1>

<p align="center">Домашний экран с виджетами для портретных головных устройств Geely OneOS</p>

Atlas Launcher заменяет домашний экран на Android: размещает приложения и системные виджеты
по сетке, показывает часы и док, позволяет выбрать фон и настроить рабочий стол.
Пакет приложения — `com.geely.atlaslauncher`.

## Интерфейс

Рабочий стол использует графитовую палитру Atlas. Долгое нажатие включает редактирование:
виджеты можно перемещать, изменять по размеру и настраивать. Часы и док добавляются как
встроенные виджеты; каталог приложений открывается из дока.

## Возможности

- стандартные Android AppWidget: добавление, повторная настройка, перемещение и изменение размера;
- сетка без перекрытий и сохранение размещения после перезапуска;
- встроенные часы с настройками шрифта, времени и даты;
- док избранных приложений, поиск и каталог всех приложений;
- встроенные фоны и выбор своего изображения;
- настройки размера значков, подписей и внешнего вида рабочего стола;
- необязательный перехват кнопок штатной климатической панели через службу специальных возможностей;
- выбор действия кнопки «Все приложения», включая GLauncher из GInputBridge;
- переход в системный выбор HOME и возврат к штатному Launcher3.

## Требования

- Android 11 на целевом ГУ Geely OneOS; минимальная версия Android — 8.0 (`minSdk 26`);
- портретный экран, целевая конфигурация — 1440×1920;
- для системных виджетов нужны установленные приложения-провайдеры;
- GInputBridge нужен только для его дополнительных функций, например GLauncher.

## Установка и запуск

1. Установите подписанный APK из [Releases](https://github.com/mmwtl/AtlasLauncher/releases).
2. Выберите **Atlas Launcher** в системном выборе домашнего приложения.
3. Долгим нажатием на рабочий стол откройте редактирование и добавьте виджеты, часы и док.
4. Настройте фон и поведение через кнопку **⚙**.

Вернуться к штатному HOME можно в карточке **«Система»** настроек. Удалять Launcher3 не требуется.
Сборки со старым пакетом `com.mmwtl.atlaslauncher` устанавливаются отдельно: для нового пакета
потребуется повторно выбрать HOME и разместить виджеты.

## Сборка и проверки

Требуются JDK 17 и Android SDK 35. Используйте Gradle Wrapper из корня проекта:

```sh
ANDROID_USER_HOME="$PWD/.android-user" sh gradlew --offline :app:assembleRelease -x :app:lintVitalRelease
```

`lintVitalRelease` пропускается из-за `ExpiredTargetSdkVersion` при `targetSdk=30`.
Это сборка для головного устройства; SDK не повышается ради требований Google Play.

Подпись подключается через игнорируемый `secure.signing.gradle` по образцу
[app/secure.signing.gradle.example](app/secure.signing.gradle.example).
APK находится в `app/build/outputs/apk/release/` и называется
`<effectiveVersionName>[<versionCode>]AtlasLauncher-release.apk`.
Без ключа получается `-unsigned` APK. Для обновления нужен тот же ключ подписи.

## Совместимость

Поведение климатической панели, OEM-виджетов, кнопок SystemUI и запуска DIM зависит от прошивки.
Лаунчер проверен на ГУ ATLAS ОД; на других прошивках эти сценарии нужно проверять отдельно,
ограничения и порядок проверки приведены в документации. Штатные Launcher3 и SystemUI должны оставаться установленными.
Если после ручной установки «Настроек» (`com.android.settings`) HOME всегда открывает Launcher3,
см. [обход](docs/launcher-settings.md#home-всегда-открывает-launcher3-после-установки-настроек).
