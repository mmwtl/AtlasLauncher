# AtlasLauncher

Устанавливаемый Android HOME для ГУ OneOS. Package name: `com.mmwtl.atlaslauncher`.

## Что работает в прототипе

- обычный HOME Activity без overlay и без скрытия системных панелей;
- полный список запускаемых приложений, поиск, запуск, избранное и его порядок;
- стандартные Android AppWidget: выбор, системная привязка, размещение по сетке без перекрытий, перетаскивание, изменение размера при поддержке провайдером и удаление;
- встроенный виджет часов, который можно добавить, переместить, изменить в размере и удалить;
- выбор фонового изображения и настройки нижнего дока;
- вход в настройки HOME и запуск штатного Launcher3 из меню.

Климатическая панель и верхнее меню принадлежат OEM SystemUI. Этот APK их не рисует и не управляет ими. Их поведение со сторонним HOME нужно проверить на реальном ГУ. GInputBridge для основных функций не требуется.

## Сборка

Требуются Android SDK с API 35 и Java 17. В обычной среде:

```sh
ANDROID_USER_HOME="$PWD/.android-user" ./gradlew :app:assembleDebug
```

Новая сборка появится в `app/build/outputs/apk/debug/app-debug.apk`. APK в `artifacts/` относятся к более раннему состоянию проекта. Для обновлений на ГУ сохраняйте тот же ключ подписи; релизную подпись перед постоянным использованием нужно настроить отдельно.

Интерфейс рассчитан только на портретный экран ГУ. Часов по умолчанию нет; их можно добавить через `⚙` → `Редактировать рабочий стол` → `＋` → `Часы AtlasLauncher`. Сохранённые виджеты показываются при обычном запуске. Область размещения занимает всё доступное поле Activity; во время редактирования док скрывается, чтобы можно было работать с нижней частью экрана. Редактирование также открывается долгим нажатием на свободное место. Кнопки добавления и завершения видны только в этом режиме. Через `⚙` можно выбрать фон, вернуть стандартный фон и настроить док: его видимость, размер, кнопку приложений и состав закреплённых приложений. При первом показе старые координаты привязываются к ближайшим свободным ячейкам сетки; размеры также округляются до ячеек. Живой карты и навигации в этой версии нет. Activity фиксирует портретную ориентацию. [Снимки прежнего оформления](qa/scenic-preview/home.png) и [отчёт прежней функциональной проверки на эмуляторе](qa/freeform-widgets/report.md).
В режиме редактирования у часов есть отдельная кнопка настроек: формат времени (`как в системе`, `24 часа`, `12 часов`), отображение даты, начертание (`тонкий`, `обычный`, `жирный`) и семейство шрифта (`без засечек`, `с засечками`, `моноширинный`). Эти параметры сохраняются отдельно от положения и размера виджета.

После установки выберите AtlasLauncher в системном выборе домашнего приложения. В меню `⚙` есть переход в настройки HOME для возврата к штатному Launcher3. Штатный APK удалять не требуется.

Подробный план и ограничения: [docs/launcher-prototype-plan.md](docs/launcher-prototype-plan.md). Исходные OEM APK для анализа: [reference-apks/README.md](reference-apks/README.md).

Пошаговая проверка на ГУ и команды возврата к штатному HOME: [docs/head-unit-test-and-rollback.md](docs/head-unit-test-and-rollback.md). Этот протокол пока не выполнялся на ГУ.
