# AtlasLauncher

Устанавливаемый Android HOME для ГУ OneOS. Package name: `com.mmwtl.atlaslauncher`.

## Что работает в прототипе

- обычный HOME Activity без overlay и без скрытия системных панелей;
- полный список запускаемых приложений, поиск, запуск, избранное и его порядок;
- стандартные Android AppWidget: выбор, системная привязка, размещение по сетке без перекрытий, перетаскивание, изменение размера при поддержке провайдером и удаление;
- встроенные виджеты часов и дока приложений: добавление, перемещение, изменение размера и удаление;
- выбор фонового изображения и настройки дока в его виджете;
- нейтральный графитовый док с одинаковыми ячейками для избранного и кнопки «Все приложения»: ширина по содержимому, горизонтальная прокрутка при переполнении;
- вход в настройки HOME и запуск штатного Launcher3 из меню.

Климатическая панель и верхнее меню принадлежат OEM SystemUI. Этот APK их не рисует и не управляет ими. Их поведение со сторонним HOME нужно проверить на реальном ГУ. GInputBridge для основных функций не требуется.

## Сборка

Требуются Android SDK с API 35 и Java 17. В обычной среде:

```sh
ANDROID_USER_HOME="$PWD/.android-user" ./gradlew :app:assembleDebug
```

Новая сборка появится в `app/build/outputs/apk/debug/app-debug.apk`. APK в `artifacts/` относятся к более раннему состоянию проекта. Для обновлений на ГУ сохраняйте тот же ключ подписи; релизную подпись перед постоянным использованием нужно настроить отдельно.

Интерфейс рассчитан только на портретный экран ГУ. Часы можно добавить через `⚙` → `Редактировать рабочий стол` → `＋` → `Часы AtlasLauncher`. Док приложений добавляется там же как встроенный виджет. При обновлении прежний видимый док переносится в сетку автоматически; если он был скрыт, его можно добавить вручную. Док можно передвинуть над нижней системной панелью, изменить его размер или удалить и позже добавить снова. При удалении список закреплённых приложений сохраняется. Сохранённые виджеты показываются при обычном запуске. Область размещения занимает всё доступное поле Activity. Редактирование также открывается долгим нажатием на свободное место. Кнопки добавления и завершения видны только в этом режиме. Настройки дока открываются долгим нажатием на его значок или шестерёнкой самого виджета в режиме редактирования. В одном окне доступны состав и порядок приложений, кнопка «Все приложения», её действие, компактный вид, размер значков и подписи каталога; закрепление приложений выполняется там же. При первом показе старые координаты привязываются к ближайшим свободным ячейкам сетки; размеры также округляются до ячеек. Живой карты и навигации в этой версии нет. Activity фиксирует портретную ориентацию. Точную позицию над OEM-панелью нужно проверить на реальном ГУ. [Снимки прежнего оформления](qa/scenic-preview/home.png) и [отчёт прежней функциональной проверки на эмуляторе](qa/freeform-widgets/report.md).
В режиме редактирования у часов есть отдельная кнопка настроек: формат времени (`как в системе`, `24 часа`, `12 часов`), отображение даты, начертание (`тонкий`, `обычный`, `жирный`) и семейство шрифта (`без засечек`, `с засечками`, `моноширинный`). Эти параметры сохраняются отдельно от положения и размера виджета. Блок встроенных часов занимает ширину времени и даты, округлённую до ячеек сетки. При обновлении существующий блок сужается с сохранением размера цифр; новый размер сохраняется после перезапуска.

Каталог «Все приложения» использует тот же графитовый стиль, что и док. Окно каталога занимает до 1200×1400 dp, его значки имеют фиксированный размер 96 dp, а подписи приложений всегда видны. Сетка подстраивается под ширину экрана. Размер значков дока (40–160 dp) и показ подписей в доке настраиваются в виджете дока. Значки дока равномерно распределяются по его ширине. В компактном режиме без подписей док с иконками до 80 dp можно уменьшить до одной ячейки 96 dp; более крупное содержимое требует больше ячеек. Параметры сохраняются после перезапуска.

В настройках дока можно изменить действие кнопки «Все приложения»: встроенный каталог, GLauncher (GIB), экспортированная Activity установленного приложения или компонент, введённый вручную как `package.name/.ActivityName`. Готовый вариант GLauncher использует `com.salat.gbinder/com.salat.gbinder.AppLauncher` — экспортированный alias из проверенного локального APK GIB 4.6.1 (1719). GIB должен быть установлен и настроен на устройстве. Переход из кнопки дока в окно GLauncher проверен на эмуляторе; на реальном ГУ пока не проверен. Если выбранная Activity недоступна или запрещена для внешнего запуска, лаунчер сообщает об этом и открывает встроенный каталог. Пункт «Приложения» в меню лаунчера всегда открывает встроенный каталог независимо от выбранного действия кнопки.

После установки выберите AtlasLauncher в системном выборе домашнего приложения. В меню `⚙` есть переход в настройки HOME для возврата к штатному Launcher3. Штатный APK удалять не требуется.

Подробный план и ограничения: [docs/launcher-prototype-plan.md](docs/launcher-prototype-plan.md). Исходные OEM APK для анализа: [reference-apks/README.md](reference-apks/README.md).
