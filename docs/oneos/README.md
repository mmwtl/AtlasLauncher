# Исследования OneOS

Что мы знаем о прошивке ГУ Geely OneOS (Android 11, G636 `1.0.20250623G(312)`; где указано — прошивка второй машины `1.0.20260326G(87)`) и почему Atlas устроен так, а не иначе. Основание — декомпиляция OEM APK и jar фреймворка из [reference-apks](../../reference-apks/README.md) и проверки на ГУ. В каждой заметке указано, что подтверждено на машине, а что выведено только из кода.

| Тема | Коротко |
| --- | --- |
| [Климатическая панель](climate-panel.md) | Плагин SystemUI выбирает вид панели по имени пакета — отсюда `com.geely.atlaslauncher`; кнопки «Домой» и «Все приложения» жёстко открывают Launcher3 |
| [Выбор HOME](home-selection.md) | Доработка `PackageManagerService`: вручную установленные «Настройки» заставляют HOME всегда открывать Launcher3 |
| [Лого загрузки](boot-logo.md) | QNX снимает лого по сигналу `DIMKeyService`, который штатно приходит только для Launcher3 |
| [Этап запуска служб](launcher-startup-stage.md) | Broadcast `com.android.launcher3.startup` запускает семь OEM-служб и ночную тему |
| [DIM-служба](dim-service.md) | Медиа и телефон на приборке: службу запускает только HOME |
| [Медиавиджет и медиацентр](media-widget.md) | Список источников штатного медиавиджета на стороннем HOME; что отдаёт медиацентр |
| [Касания](touch-input.md) | OEM «Назад» от края экрана; глобальный фильтр касаний доступен обычному APK |
| [XCGestureService](gesture-service.md) | Почему штатные жесты пропадают после перезагрузки |
| [Строка состояния](status-bar.md) | Почему на G636 нет плашки «Сейчас играет» и как показать свой текст |
| [Дисплеи](displays.md) | Приборку и HUD рисует QNX; дополнительные дисплеи Android никуда не выводятся |
| [OneOS API и прочие службы](oneos-api.md) | `OneOSApiService`, провайдер климата, проверки Launcher3 во фреймворке |
| [Подписи прошивки](firmware-signatures.md) | Все OEM APK подписаны одним закрытым ключом; менять их нельзя |
