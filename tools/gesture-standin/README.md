# Подставная служба касаний для эмулятора

На эмуляторе нет `EcarxInputDispatcherService`, поэтому жесты AtlasLauncher там не получают касаний. `FakeDispatcher` регистрирует службу с тем же Binder-протоколом ([docs/oneos/touch-input.md](../../docs/oneos/touch-input.md)), забирает сенсор эмулятора и пропускает касания через фильтр AtlasLauncher, как на ГУ. Мышь при этом изображает несколько пальцев.

Только для эмулятора: служба захватывает сенсор и занимает имя системной службы OneOS. `start.sh` отказывается работать, если устройство не эмулятор.

## Запуск

Нужны JDK 17, Android SDK (`ANDROID_HOME`, по умолчанию `~/Library/Android/sdk`) с платформой API 35 и build-tools, эмулятор с root (образ без Google Play) и экраном 1440×1920. Устройство — `ANDROID_SERIAL`, по умолчанию `emulator-5554`.

```sh
sh tools/gesture-standin/start.sh   # собрать, запустить, перезапустить Atlas
sh tools/gesture-standin/stop.sh    # остановить, сенсор возвращается системе
```

`start.sh` сначала останавливает прежний экземпляр, отключает SELinux (`setenforce 0`, до перезагрузки эмулятора) и перезапускает AtlasLauncher: служба жестов ищет диспетчер при старте. Журнал — `/data/local/tmp/fd.log` на эмуляторе.

## Жесты мышью

В окне эмулятора нажмите цифру, затем тяните мышью:

| Клавиша | Касание |
|---|---|
| 2, 3, 4 | столько пальцев вокруг курсора |
| 5 | четыре пальца сводятся при движении вниз и расходятся при движении вверх |

Нажатая и отпущенная цифра действует на одно касание, зажатая — пока её держат. Без цифры мышь — один палец. Короткий щелчок после цифры — касание несколькими пальцами.

Курсор — центр пальцев: два стоят в 70 px слева и справа, три — в 100 px по бокам и один на 150 px ниже, четыре — в ряд через 120 px. Для зон двух пальцев у краёв держите оба пальца в одной четверти экрана. Цифра доходит и до Android, в открытое поле ввода она напечатается.

## Жесты из скрипта

Строка в `/data/local/tmp/fd_cmd` выполняется как жест: `x,y;x,y;… dx dy масштаб мс_движения мс_удержания`. Пальцы опускаются по очереди, затем все вместе сдвигаются на `dx dy` и меняют расстояние до центра в `масштаб` раз:

```sh
adb shell 'echo "520,900;920,900;720,1050 0 -400 1 600 300" > /data/local/tmp/fd_cmd'
```

## Ограничения

- `screencap` и `Thread.sleep` на эмуляторе сильно тормозят: пороги времени (касание 0,4 с, пауза 200 мс) проверяются JVM-тестами, а не здесь.
- Без шкалы температура и яркость видимого эффекта не дают: автомобиля нет. Громкость меняется по-настоящему.
- Экран окна поверх приложений рисуется медленно на `swiftshader_indirect`; запускайте эмулятор с `-gpu host`.
